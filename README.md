# Портфолио Алины Япаровой

Статичный сайт-портфолио: `index.html`, картинки в `img/`, иконка `favicon.svg`. Сборка не нужна.

## Как опубликовать на GitHub Pages

1. Создать аккаунт на github.com (если нет).
2. Создать новый **публичный** репозиторий, например `portfolio`.
3. На странице репозитория: **Add file → Upload files**, перетащить всё содержимое папки (`index.html`, `favicon.svg`, `README.md` и папку `img`), нажать **Commit changes**.
4. **Settings → Pages** → в блоке *Build and deployment* выбрать *Source: Deploy from a branch*, ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<имя-пользователя>.github.io/portfolio/`.

Если назвать репозиторий `<имя-пользователя>.github.io`, адрес будет короче: `https://<имя-пользователя>.github.io/`.

## Как обновить

- Заменить картинку: загрузить новый файл с тем же именем в `img/` (формат WebP или поменять расширение в `index.html`).
- Поменять текст: открыть `index.html` на GitHub → значок карандаша → править → **Commit changes**.
